AI Engineer Path — Карим

Меня зовут Карим. Я захожу в AI Engineering с нуля — до этого не программировал,
но есть базовый опыт в другой сфере IT.

## Цель
Дойти до уровня уверенного Middle/Senior AI Engineer за 6–9 месяцев и
трудоустроиться в продуктовую компанию (рассматриваю и СНГ, и международный
удалённый рынок).

## Формат обучения
3 часа в день, 5 дней в неделю, по роадмапу из 10 фаз:
Python → Математика для ML → Классический ML → Deep Learning → NLP/Transformers →
LLM/RAG → Fine-tuning → MLOps/деплой → AI-агенты → подготовка к трудоустройству.
